Pointing nicacct.com at the new website

For whoever manages the GoDaddy (or other registrar) account for nicacct.com. This is a DNS change only — about ten minutes. No website files are involved.

Step 1 — open DNS management

Log in to the registrar → My Domains → nicacct.com → DNS / "Manage DNS" / "DNS Records".

Step 2 — replace the website records

Delete any existing A records for @ and any CNAME for www, then add these six records:

TypeNameValueTTL
A@185.199.108.1531 hour
A@185.199.109.1531 hour
A@185.199.110.1531 hour
A@185.199.111.1531 hour
CNAMEwwwjcurry44.github.io1 hour
Do not touch anything else. In particular, leave every MX record and any TXT/SPF/DKIM records exactly as they are — those run the firm’s email (admin@nicacct.com). This change affects only the website.

Step 3 — tell Joe it's done

That’s the whole job on your side. Joe completes the connection and the secure certificate issues automatically. The new site appears at nicacct.com within minutes to a few hours (rarely up to 24) as the change propagates.

What this does

  • The website itself is hosted (free) on GitHub Pages and managed by Joe — updates never require touching GoDaddy again.
  • Whatever the domain pointed at before will stop being served — if an old site exists and should be archived first, say so before making the change.
  • Email is unaffected. The records that route mail are not being modified.
